# キャロットクラブ 申込状況インポートスキル

公表テキストをパースして `app/tools/import_application_status.py` でDBに登録し、倍率プレビューをユーザーに伝える。

---

## 公表テキストのフォーマット

```
第N回
XX.X％          ← 前年比申込状況
M/D             ← 公表日

＜母馬優先対象馬＞
08番　スルーセブンシーズの25　258口　97口　6口　57口
  └─ 番号  馬名  [総申込]口  [母馬優先+最優先]口  [母馬優先(一般)]口  [最優先]口

※口数は左から「総申込」「母馬優先＋最優先」「母馬優先（一般）」「最優先」となります。

＜母馬優先非対象馬＞
03番　ジェイウォークの25　209口　93口
  └─ 番号  馬名  [総申込]口  [最優先]口
```

**母馬優先対象馬**: 口数4列。左から 総申込 / 母馬優先+最優先 / 母馬優先(一般) / 最優先。

**母馬優先非対象馬**: 口数2列。左から 総申込 / 最優先のみ（母馬優先なし）。

---

## 必須情報の確認（最初に行う）

パースやコマンド実行の前に、以下の情報が揃っているか確認する。
**1つでも不明・不確かな場合は必ずユーザーに確認してから進むこと。勝手に推測して進めない。**

| 情報 | 読み取り元 | 不明な場合 |
|------|-----------|-----------|
| `announcement_no` | テキスト中の「第N回」 | 「第何回の公表ですか？」と聞く |
| `prev_year_ratio` | テキスト中の「XX.X%」 | 「前年比（%）を教えてください」と聞く |
| `announced_date` | テキスト中の「M/D」 | 「公表日を教えてください（例: 9/3）」と聞く |
| `year` | scoringYear（通常2026） | 「募集年は何年ですか？」と聞く |
| 馬データ | ＜母馬優先対象馬＞＜母馬優先非対象馬＞セクション | テキストがなければ貼り付けを依頼する |

確認が取れてから次のステップへ進む。

---

## パース手順

### ステップ1: メタデータを読み取る

| 項目 | 読み取り方 | 変換例 |
|------|-----------|--------|
| `announcement_no` | 「第N回」のN | 第1回 → `1` |
| `prev_year_ratio` | XX.X% を小数に変換 | 16.6% → `0.166` |
| `announced_date` | M/D を年付きISOに変換 | 9/3 → `2026-09-03`（年はscoringYearを参照） |
| `year` | アプリのscoringYear | `2026` |

### ステップ2: 各馬のデータをJSONに変換

**母馬優先対象馬**（4列）:
```json
{
  "horse_name": "スルーセブンシーズの25",
  "total_applications": 258,
  "priority_tickets": 97,
  "mother_general_count": 6,
  "top_priority_count": 57
}
```

**母馬優先非対象馬**（2列）:
```json
{
  "horse_name": "ジェイウォークの25",
  "total_applications": 209,
  "priority_tickets": 93,
  "mother_general_count": 0,
  "top_priority_count": 93
}
```
→ `priority_tickets` と `top_priority_count` に同じ値（2列目）を入れ、`mother_general_count` は 0。

馬名の `の25`/`の2025` 表記ゆれはツール側で自動解決されるので、公表テキストそのままでよい。

### ステップ3: インポートコマンドを実行

```bash
python3 -m app.tools.import_application_status \
  --db shared/userdata.db \
  --year YEAR \
  --announcement-no N \
  --prev-year-ratio RATIO \
  --announced-date DATE \
  --data 'JSON配列'
```

- コマンドは必ず `python3 -m` で実行（`python` は使えない）
- `--data` の値はシングルクォートで囲む
- 全馬を1つのJSON配列にまとめて一度で実行する

### ステップ4: 結果を報告

コマンド出力の倍率プレビューをユーザーに伝える。
「Streamlitをリロードすると候補馬一覧に倍率が反映されます」と添える。

---

## 倍率の読み方（ユーザーへの補足説明用）

- **最優先倍率**: 1.0倍未満 = 「当確」（全員当選）。数字が大きいほど競争率高。
- **一般倍率**: 最優先倍率が1倍を超えると `-`（一般枠が実質なくなる）。
- 第1回公表は早期のため前年比が低く（16%前後）、倍率が大きく出る傾向がある。最終的な倍率は第2回以降で精度が上がる。

---

## 実行例

第1回公表（前年比16.6%、9月3日）のデータを登録する場合:

```bash
python3 -m app.tools.import_application_status \
  --db shared/userdata.db \
  --year 2026 \
  --announcement-no 1 \
  --prev-year-ratio 0.166 \
  --announced-date 2026-09-03 \
  --data '[{"horse_name":"スルーセブンシーズの25","total_applications":258,"priority_tickets":97,"mother_general_count":6,"top_priority_count":57}]'
```
